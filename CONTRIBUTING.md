# Contributing

Thanks for your interest in KalorienKompass.

## Issues

Bug reports and ideas are welcome as GitHub issues. This is a personal project maintained in spare time, so there is no guaranteed response time or support.

## Pull requests

- Keep changes focused; one topic per pull request.
- New calculation or parsing logic needs a test (Swift Testing, see the README).
- The user interface is German; please keep new UI texts German.

## Developer Certificate of Origin

Every commit must be signed off to certify that you wrote the change or otherwise have the right to submit it under the project's license, as described in the [Developer Certificate of Origin](https://developercertificate.org):

```bash
git commit -s -m "Your message"
```

This adds a `Signed-off-by: Your Name <you@example.com>` line to the commit.
